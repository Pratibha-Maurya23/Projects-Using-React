# 🧠 MindLeap — Start Your Journey to Mental Wellness

MindLeap is a premium, fully responsive, and beautifully animated mental wellness landing page. It is crafted with modern design patterns using React 19, Tailwind CSS v4, Motion (formerly Framer Motion), and Vite. MindLeap is designed to help users connect with professional therapists, explore mindfulness guides, practice meditation, and book wellness counseling sessions.

🚀 **Live Demo:** [https://projects-using-react-lt7c.vercel.app/](https://projects-using-react-lt7c.vercel.app/)

---

## 🌟 Key Features

- **💫 Gorgeous Animations:** Built-in viewport animations, scroll fades, and smooth transitions powered by **Motion** (Framer Motion).
- **📱 Fully Responsive Layout:** Designed using a mobile-first approach with Tailwind CSS v4.
- **🧭 Interactive Sticky Navigation:** Responsive menu with active link highlighting and mobile-friendly drawer.
- **🛠️ Dedicated Service Section:** Showcases diverse counseling programs (Depression, Anxiety, Relationship, Personal Growth) with clean interactive layouts.
- **📈 Interactive Steps Guide:** Shows users exactly how the registration and session matching works step-by-step.
- **💳 Pricing Plans:** Clean comparison structure with customized pricing categories for individuals, couples, and premium packages.
- **💬 Testimonials Carousel/Review Grid:** Dynamic showcase of verified patient stories and positive feedback.
- **✉️ Interactive Contact Form:** Built-in form with real-time validated fields for booking first consultation sessions.

## 🛠️ Tech Stack & Packages

- **Frontend Core:** [React 19](https://react.dev/) & [Vite 7](https://vite.dev/)

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1. Clone the repository and navigate to the project directory:
```bash
git clone https://github.com/Pratibha-Maurya23/Projects-Using-React.git
cd Projects-Using-React/MindLeap
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start the Vite development server:
```bash
npm run dev
```

### 4. Build for production:
```bash
npm run build
```
