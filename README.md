## 🛠️ Project Highlights

### 1. 🛍️ [Myntra Clone](./Myntra%20Clone%20using%20React/)
* **Category:** Full-Stack E-Commerce
* **Key Features:**
  - Product catalog page with dynamic item grids.
  - Interactive shopping bag enabling live item additions and deletions.
  - Live bag order checkout summary (MRP, discount details, convenience fees).
  - Redux Toolkit for unified global state storage.
  - Custom Express.js API server to serve product data.

### 2. 🧠 [MindLeap](./MindLeap/)
* **Category:** Animated Landing Page
* **Key Features:**
  - Designed using mobile-first practices with Tailwind CSS v4.
  - Dynamic scroll and viewport animations driven by Motion v12.
  - Responsive menu layouts with sticky navigation anchors.
  - Interactive steps timeline, service grids, and testomonial carousels.

### 3. 📅 [Interactive Wall Calendar](./takeUfarwordAssisment/)
* **Category:** Creative UI Component
* **Key Features:**
  - Physical calendar emulation utilizing custom polygon clip-paths.
  - Intuitive range selection with validation rules for start/end dates.
  - Integrated notes/memo pad side interface.
  - Glassmorphic navigation headers with backdrop-blur styling.

### 4. 💻 [Personal Developer Portfolio](./demo-portfolio-react/)
* **Category:** Personal Branding Website
* **Key Features:**
  - Completely responsive layouts using custom CSS grid configurations.
  - Real-time skin colors customizable through CSS custom properties.
  - System-preference-aware light/dark mode persistence via `localStorage`.
  - Section visibility trackers dynamically updating navigation markers.

### 5. 💬 [Social Media App](./7-social%20Media%20version-7/)
* **Category:** State Management Practice
* **Key Features:**
  - Context API (`post-list-store`) for state mapping.
  - Post creation portal handling custom tags, content, and author details.
  - Responsive sidebar and header templates using Bootstrap classes.

## 🚀 How to Run Locally

Since each project in this monorepo is self-contained:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Pratibha-Maurya23/Projects-Using-React.git
   cd Projects-Using-React
   ```

2. **Navigate into the target project folder:**
   ```bash
   cd "Myntra Clone using React" # Example for Myntra Clone
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
